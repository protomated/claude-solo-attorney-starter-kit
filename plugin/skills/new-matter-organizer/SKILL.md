# /new-matter-organizer — New-Matter Setup & Document Organizer Skill

> ⚠️ AI-ASSISTED DRAFT — ATTORNEY REVIEW REQUIRED
> This output was generated by an AI assistant. Review the proposed folder structure and task checklist before confirming. This is not legal advice.

Set up a new matter folder with the standard directory structure for the practice area, populate a starter task checklist, and sort any existing documents into the right sub-folders. Everything is shown first — no folders or files are created without your explicit confirmation.

**This skill proposes folder structures and file moves. No changes are made without your explicit in-conversation confirmation.**

## Invocation

```
/new-matter-organizer [matter name] [practice area]
/new-matter-organizer "Smith-PI" "personal injury"
/new-matter-organizer "Acme-Contract" "contract dispute"
```

Supported practice areas: personal injury, family law, criminal defense, estate planning / probate, immigration, real estate, employment, contract dispute, general.

---

## Workflow

### Step 1 — Gather inputs

Ask or infer from the argument:
1. **Matter name** — the folder name to use (e.g., `Smith-John-PI`, `Nguyen-Divorce-2026`). Suggest a consistent naming convention: `LastName-FirstName-PracticeArea` or `LastName-Matter-Year`.
2. **Practice area** — determines the folder template and starter checklist.
3. **Parent folder path** — where to create the new matter folder inside the Filesystem-connected workspace (e.g., `~/Matters/`). Ask if not obvious from prior matters.
4. **Existing documents** — are there any documents in an inbox or downloads folder to sort into this new matter? If yes, ask for the source path.

### Step 2 — Read existing matter structure for consistency

Use the Filesystem connector to scan the workspace folder (one level deep) for existing matter folders. Note the naming convention and folder structure used in prior matters — propose a new folder that follows the same pattern.

### Step 4 — Propose the starter task checklist

Generate a practice-area-appropriate task checklist and save it as `tasks.md` inside the new matter folder. Present it first:

```markdown
# [Matter Name] — Task Checklist
**Opened:** [Date]
**Practice Area:** [Type]
**Status:** Active

---

## Immediate (first 48 hours)
- [ ] Run /intake-summary to create the matter brief
- [ ] Conflicts check — run names: [leave blank for attorney to fill]
- [ ] Confirm statute of limitations date
- [ ] Confirm fee agreement / send engagement letter (/engagement-letter)
- [ ] [Practice-area-specific immediate task]

## This Week
- [ ] [Task]
- [ ] [Task]

## Ongoing
- [ ] [Recurring task]
```

Ask:
> "Here is the starter task checklist. I'll save this as `tasks.md` in the new matter folder along with the folder structure above. Confirm to create everything, or request changes."

### Step 5 — Sort existing documents (optional)

If the attorney indicated there are existing documents to file, use the Filesystem connector to read the file names and types from the source folder. Propose a mapping:

```
[filename1.pdf] → [MatterName]/medical/records/
[filename2.docx] → [MatterName]/correspondence/client/
[filename3.jpg] → [MatterName]/evidence/photos/
```

Present the proposed mapping and ask for confirmation before moving any file.

> "Here is how I'd sort the existing documents. Say 'yes, move them' to proceed, 'skip' to create the folder structure without moving files, or tell me what to adjust."

Do not move or copy any file without explicit confirmation.

### Step 6 — Create the folders and files

After receiving explicit confirmation:
1. Create the folder tree using the Filesystem connector.
2. Write `tasks.md` with the confirmed task checklist.
3. Move any confirmed document files to their proposed locations.
4. Write a brief `README.md` at the matter root:

```markdown
# [Matter Name]
**Opened:** [Date]
**Practice Area:** [Type]
**Client:** [Leave blank — fill after running /intake-summary]

Run `/intake-summary` to create the `intake-summary.md` anchor document.
All other skills read from `intake-summary.md`.
```

Confirm completion:
> "Done — matter folder created at [path]. Next step: run `/intake-summary` to create the matter brief that all other skills read from."

## What This Skill Does Not Do

- It does not create any folders, files, or move any documents without your explicit confirmation.
- It does not analyze the content of documents to determine privilege or relevance.
- It does not open the file in your practice-management system (Clio, MyCase, etc.) — it works with your local filesystem only.
- It does not perform a conflicts check — it prompts you to do so in the task checklist.
